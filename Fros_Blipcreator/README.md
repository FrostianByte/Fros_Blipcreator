
🗺️ Fros BlipCreator
Fros BlipCreator ist ein einfaches und benutzerfreundliches Tool zum Erstellen und Verwalten von Blips auf der Karte in GTA V FiveM. Mit diesem Script kannst du benutzerdefinierte Blips einfach konfigurieren und auf deinem Server anzeigen lassen.

✅ Features
Einfaches Erstellen und Platzieren von Blips

Unterstützung für verschiedene Blip-Icons und Farben

Live-Vorschau auf der Karte

Konfigurierbare Namen, Farben, Koordinaten, Skalierung etc.

Perfekt geeignet für Admins oder Mapper

🔧 Kompatibilität
✅ ESX: Getestet und funktioniert einwandfrei

❌ QBCore: Nicht Getestet

📝 Installation
Script in deinen resources Ordner legen:

resources/fros_blipcreator
In die server.cfg eintragen:

ensure fros_blipcreator
